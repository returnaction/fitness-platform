# Решения и открытые вопросы Spec 018

Общие решения собраны в [decisions.md](decisions.md).
Этот документ не содержит индивидуальных параметров серверной среды.

## Уточнения реализации

| Вопрос | Принятое решение | Задачи |
| --- | --- | --- |
| Стартовые версии | Собственные версии сервисов и gRPC-контрактов — 0.1.1; общий POM остаётся 0.1.0-SNAPSHOT | T001 |
| Общие контракты | Потребитель явно выбирает версию библиотеки; локальная и Docker-сборка используют одинаковое правило | T001 |
| Имя JAR | Dockerfile не содержит фиксированного номера версии JAR | T001 |
| Профили | Dev-профили и серверные шаблоны подготовлены для всех сервисов; первый запуск ограничен четырьмя | T002 |
| Первый выпуск | XML-парсер учитывает переход от наследуемой SNAPSHOT-версии к release | T003 |
| Несколько выпусков | Очередь целых выпусков и защита от понижения версии; последовательный запуск внутри выпуска | T003 |
| Ошибка запуска | Остановка дальнейшей выкладки, сохранение диагностики без автоматического отката | T003, T005 |
| Публикация документации | В репозитории остаются общие требования и результаты; индивидуальный операционный журнал хранится отдельно | T006 |

## Отложенные решения

| Вопрос | Когда вернуться | Основание |
| --- | --- | --- |
| Точные лимиты RAM/JVM | После первого измерения | Нет данных о реальном потреблении |
| Порядок последующего обновления сертификатов | До истечения срока действия | Автоматическая ротация не входит в первый выпуск |
| Доступ команды | При появлении участника | Нужен конкретный набор разрешений |
| Сверка system-design с реализованной средой | После первого выпуска | Описывать подтверждённый результат |

## Ограничения проверки

Наличие настройки или локального теста не означает успешный выпуск.
Непроверенные части цепочки перечислены в [verification.md](verification.md)
и остаются открытыми в [tasks.md](tasks.md).
