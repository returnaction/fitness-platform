# Проверки Spec 018

> **Статус:** implemented
> **Задачи:** [tasks.md](tasks.md)

Публичная сводка результатов на 2026-11-16. Адреса среды, учётные записи,
пути секретов, отпечатки ключей и полный операционный журнал хранятся у владельца.

## Репозиторий и конфигурация

- Maven Wrapper успешно проверил общие модули и первый набор сервисов.
  Собственные версии сервисов и контрактов — 0.1.1, root POM — 0.1.0-SNAPSHOT.
- Четыре Dockerfile собраны локально и в CI. Разбор Compose успешен;
  конфигурация использована при реальной выкладке. Наружу опубликован Gateway.
- Серверные настройки сверены с шаблонами; права файлов и криптографические
  материалы проверены без публикации значений секретов.

## Инфраструктура и первый выпуск

- Подтверждены SSH по ключу, сетевые ограничения, UTC/NTP и минимальный набор ПО.
- PostgreSQL 17 работает вне Docker. Проверены DBeaver через SSH-туннель,
  аутентификация, владельцы баз и запрет подключения роли к чужим сервисным БД.
- [PR #53](https://github.com/returnaction/fitness-platform/pull/53) слит в main.
  [Выпуск 43761942692](https://github.com/returnaction/fitness-platform/actions/runs/43761942692)
  для commit 75c4c836a53b180c81d9ff95233bce4b8f4fd143 завершился success:
  поиск версий, четыре Maven/build/publish jobs и последовательная SSH-выкладка.
- Реальное использование отдельного ключа Actions и registry подтверждено.
- Accounts, Coins, Identity и Gateway версии 0.1.1 — healthy.
- После разрешённой перезагрузки изменился boot ID; PostgreSQL и четыре
  контейнера восстановились автоматически, без ручного запуска.

## Базы и HTTP-сценарии

- Liquibase: Accounts — 1/1, Coins — 1/1, Identity — 2/2 changesets, все EXECUTED.
  Идентификаторы, авторы и пути совпадают с changelog внутри работающих JAR.
- Блокировки Liquibase отсутствуют; логи подтверждают отсутствие новых миграций
  для выполнения. Проверка выполнена в READ ONLY транзакциях, без изменения БД.
- Регистрация через Gateway вернула 201; связанные записи подтверждены
  в Identity, Accounts и Coins, в том числе владельцем через DBeaver.
- Login вернул 200; защищённый запрос с токеном — 200. Без токена,
  с неверным токеном и с неверным паролем получены ожидаемые 401.
- Проверка телефона исключена владельцем из объёма. HTTP-проверки проводились
  с компьютера и не выдаются за проверку установленного мобильного клиента.

## Образы и секреты

- API GitHub подтвердил public visibility всех четырёх пакетов; владелец
  согласовал оставить её публичной вместо первоначального private.
- Проверены Dockerfile, .dockerignore, metadata, история и все слои четырёх
  опубликованных образов 0.1.1, включая JAR и вложенные библиотеки.
- Серверных env, паролей, токенов и приватных ключей проекта не обнаружено.
  Сравнение с известными серверными секретами выполнялось только в памяти.
- Найденные библиотечные ключи сверены с публичными исходниками Netty/GnuTLS:
  это встроенные ключи самотестирования, а не ключи среды.
- Временные архивы удалены, контейнеры не перезапускались. Проверка относится
  к исследованным образам, не гарантирует отсутствие любого возможного секрета
  в будущих версиях и не охватывает CI artifacts или удалённый build cache.

- 13 локальных тестов покрыли версии/POM, порядок, отказ pull/up, нездоровую

  старого image при следующем выпуске на VPS отдельно не проверялись.
