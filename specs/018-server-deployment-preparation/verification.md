# Проверки Spec 018

> **Статус:** in-progress
> **Задачи:** [tasks.md](tasks.md)

Публичная сводка результатов на 2026-11-15. Индивидуальные параметры среды,
учётные записи, пути секретов, отпечатки ключей и подробный операционный журнал
хранятся отдельно у владельца. Сводка не заменяет проверки первого выпуска.

## Репозиторий и конфигурация

- Maven Wrapper собрал и протестировал общие модули и первый набор сервисов
  при выполнении T001. Независимые версии сервисов и контрактов — 0.1.1.
- Разбор Compose успешен локально и установленной на VPS версией Docker.
  Описаны четыре сервиса; наружу публикуется только Gateway.
- Серверные файлы настроек сверены с шаблонами: наборы переменных соответствуют,
  связанные настройки JWT согласованы. Права файлов проверены без вывода секретов.
- В отслеживаемых runtime-файлах не обнаружены реальные пароли и приватные ключи.
  Совпадения по формату ключей в Java-тестах относятся к тестовой обработке.

## Инфраструктура

- Подтверждены установка минимального набора программ, SSH-доступ по ключу,
  правила сетевого доступа, UTC и синхронизация времени.
- PostgreSQL 17 установлен вне Docker; парольная аутентификация и DBeaver
  через SSH-туннель проверены. Публичное подключение к БД недоступно.
- Проверены владельцы и права трёх сервисных БД. Каждая прикладная роль
  может подключаться к своей базе и не имеет CONNECT к двум чужим.
- Подтверждены генерация, действительность цепочек mTLS-сертификатов,
  соответствие сертификатов ключам и соответствие пары JWT-ключей.
- Права каталогов настроек и дампов проверены. Инфраструктурные службы
  восстановились после реальной перезагрузки VPS.
- Авторизация VPS в registry выполнена. Это не подтверждает скачивание
  конкретного закрытого образа проекта.

## Логика выпуска

- 13 локальных тестов release-скриптов прошли: XML/POM, первый переход с
  SNAPSHOT, сравнение версий, порядок запуска, остановка при ошибках,
  нездоровая зависимость, устаревший выпуск и повтор неудачной попытки.
- Проверка Git-истории относительно main дала четыре кандидата первого выпуска;
  проверка без повышения версии дала пустой список.
- Bash syntax check и git diff --check успешны.
- В тестах Docker заменён тестовой командой, а flock на Windows — заглушкой.
  Это не проверка настоящей конкурентной блокировки Linux или очереди GitHub.
- actionlint 1.7.12 не распознаёт документированный GitHub ключ очереди.
  Остальные проверки прошли с исключением только этой диагностики;
  ShellCheck/Pyflakes были отключены. Bash и Python проверены отдельно.
  Основание настройки очереди: [документация GitHub](https://docs.github.com/en/actions/how-tos/write-workflows/choose-when-workflows-run/control-workflow-concurrency).
- Отдельный ключ автоматизации проверен владельцем через SSH; GitHub API
  подтвердил наличие требуемых настроек. Их использование runner ещё не проверено.

Среда проверки: Docker Desktop 4.35.1 / Engine 27.3.1. Подтверждены Temurin
25.0.5+8, curl, пользователь без root UID, читаемый JAR и запись дампов.

эта проверка не заменяет Maven verify в release workflow.
