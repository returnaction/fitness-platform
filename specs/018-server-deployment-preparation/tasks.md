# Задачи: подготовка односерверной dev-выкладки

> **Спецификация:** [spec.md](spec.md)
> **План:** [plan.md](plan.md)
> **Статус:** in-progress

Авторизованы подготовка репозитория, инфраструктуры и локальные проверки.
Фактический выпуск, миграции, commit/push/merge требуют отдельного разрешения.
Индивидуальные параметры среды и подробный операционный журнал не публикуются.
