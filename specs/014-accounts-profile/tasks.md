- [ ] T005 — Реализовать GET своего профиля. Зависит от T004. UUID только из контекста; чтение по user_id; полный ProfileResponse с явным null и no-store; отсутствие профиля → 503 без создания. Проверить недоступность БД и невозможность выбрать другого владельца.

- [ ] T007 — Реализовать PUT с атомарным UPDATE RETURNING. Зависит от T006.
