# Решения grilling: мобильный профиль

> **Спецификация:** [spec.md](spec.md)  
> **Дата согласования:** 2026-11-13. Источник: ответы пользователя в чате.

| Вопросы | Итоговое решение | Задачи |
| --- | --- | --- |
| Q1–Q5 | Свой профиль, отдельная форма, английский UI, без принудительного заполнения; дополнительные функции вне объёма. Навигация уточнена в Q6. | T004–T005 |
| Q6 | Сохранить You are signed in; нижняя панель как раньше, Home/Challenges отключены, Profile справа доступен. Предложение убрать панель отклонено. | T004 |
| Q7, Q11 | Все поля ответа кроме version, пустые значения Not set; необязательные поля можно очистить. | T004–T005 |
| Q8 | Public/Private редактируются. Предложение оставить только чтение отклонено. | T005 |
| Q9 | Ручной выбор timezone из списка как раньше; автоматическое изменение не требуется. | T005 |
| Q10 | Иконка выхода справа вверху; это устройство / все устройства / отмена, существующая семантика выхода. | T004 |
| Q12 | Save без изменений закрывает форму без PUT; с изменениями отправляет PUT. | T005 |
| Q13 | Уход без сохранения отбрасывает черновик без подтверждения. | T005 |
| Q14 | Ошибки около полей по образцу старого UI, но с актуальными правилами API. | T005 |
| Q15, Q18 | Ошибка версии, без сравнения/слияния. Reload явно заменяет форму; до загрузки повторный Save блокирован. | T006 |
| Q16, Q19 | После таймаута GET для проверки, совпадение значений подтверждает состояние; иначе неопределённость и Reload. Не повторять PUT автоматически. | T006 |
| Q17, Q26 | Retry без данных; при ошибке обновления сохранить старые данные; защита от устаревших ответов. | T003–T004 |
| Q20 | Переиспользовать refresh; окончательная недействительность сессии очищает профиль и черновик. | T002–T003 |
| Q21, Q29 | При наличии локальной копии GET только вручную; исключения — конфликт и неопределённый PUT. | T003 |
| Q22–Q24 | Уход во время PUT доступен, запрос продолжается, без принудительного возврата; повторные Save/редактирование блокированы. | T006 |
| Q25, Q28 | Сохранять профиль на телефоне между запусками, защищённо и по аккаунту; при выходе удалить. Хранение только в памяти процесса отклонено. | T003 |
| Q27 | Выход во время PUT разрешён, поздние ответы игнорируются. | T006 |
| Q30 | Маркер незавершённого PUT; после прерывания приложения проверить результат через GET. | T003, T006 |
| Дополнение пользователя | Только frontend; необходимость менять backend/API сначала сообщить и отдельно обсудить. | Все |
| Проверка на телефоне | Пользователь подключит устройство; провести реальные сценарии и записать доказательства, при отсутствии управления дать пользователю шаги. | T008 |

Открытых продуктовых вопросов по пройденным раундам нет. При новых фактах
записывать вопрос, доказательства, варианты, рекомендацию и заблокированные задачи;
не менять согласованные правила молча. Разрешение на реализацию не получено.
