# Заготовки будущих микросервисов

> **Статус:** implemented  
> **Номер:** 004  
> **Контекст:** [карта сервисов](../../system-design/overview/37-service-contracts-worklist.md)

## Цель

Подготовить единообразную основу, которую разработчик сможет открыть в IntelliJ,
собрать и использовать при реализации своей задачи.

## Границы

Создать заготовки Challenge, Video Proof, Moderation, Exercise Catalog и
Notifications в `services/`. Для каждого — дочерний Maven POM, главный класс
Spring Boot, минимальная конфигурация, Dockerfile, тестовая конфигурация и README. Подключить
модули к корневой сборке. Порты задаются явно через переменные окружения.

Не входят: бизнес-функции, модели, API и gRPC-контракты, таблицы, базы,
миграции, Kafka, RabbitMQ, S3, развёртывание и настройка серверов. Наличие
заготовки не означает готовности сервиса или согласования его контрактов.

## Критерии готовности

- [x] Пять модулей имеют единообразную структуру и наследуют общий POM.
- [x] Каждый запускается с явно заданным портом; пользовательские HTTP-маршруты не открыты.
- [x] Тест HTTP каждого нового модуля и общая Maven-проверка проходят; пропуски существующих тестов отмечены в tasks.md.
- [x] README объясняет назначение, запуск и ограничения каждой заготовки.
- [x] Для каждого нового сервиса добавлен Dockerfile и проверена сборка образа.
- [x] Dockerfile Identity, Accounts и Coins учитывают новые модули; образы собраны.
- [x] Тесты каждого нового сервиса используют отдельный профиль и application-test.yaml.
- [x] Локальные проверки метрик и HTTP-доступа прошли; серверная сеть остаётся вне задачи.
- [x] Фактические проверки и ограничения отмечены в tasks.md.
