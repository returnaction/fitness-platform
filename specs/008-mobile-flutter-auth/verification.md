# Проверка Spec 008

## Физический Android по USB — 2026-11-11

Проверена debug-версия Fitness App на Samsung SM-S938B. Клиент использует
`API_BASE_URL=http://127.0.0.1:8088`, настроен `adb reverse tcp:8088 tcp:8088`.
Backend запущен из основного checkout; копирование локальных конфигураций
в worktree само по себе не означает проверку запуска backend из worktree.

Результаты подтверждены UI-иерархией телефона и счётчиками
`http_server_requests_seconds_count` на management-порту Gateway 8089:

| Сценарий | Наблюдение |
| --- | --- |
| Регистрация | Первый запрос получил Gateway 504. Повтор неизменной открытой формы завершился 201, появился `You are signed in`. |
| Перезапуск | После force-stop и запуска приложения показан `You are signed in`; Gateway зарегистрировал refresh 200. |
| Logout | Gateway зарегистрировал 204, телефон вернулся на Welcome. |
| Login | Вход тестового пользователя с телефона завершился успешно, показан `You are signed in`. |
| Logout-all | Отображён диалог подтверждения; после подтверждения Gateway зарегистрировал 204, телефон вернулся на Welcome. |
| Отзыв второй сессии | Перед подтверждением logout-all создана дополнительная тестовая сессия через Gateway. После выхода с телефона её access-token получил 401 `invalid_access_token` на logout-all. Метрики CheckSession: один `active`, один `invalid`. |

На момент снятия метрик: register 504 ×1 и 201 ×1, login 200 ×3
(один с телефона и два контрольных запроса), refresh 200 ×1, logout 204 ×1,
logout-all 204 ×1, отклонённый запрос 401 ×1.
Тестовый пользователь создан в разрешённой локальной тестовой БД;
его учётные данные и токены в документ не включены.

## Ограничения и оставшаяся работа

- Причина превышения времени первого register не установлена. Успешный повтор
  подтверждён; устранение первопричины задержки не заявляется.
- Не выполнена проверка Android Emulator.
- Не проверены на устройстве временный 503, потеря ответа refresh,
  ошибки secure storage и выход при недоступном backend.
- Наличие 12 прошедших тестов в предыдущем этапе не покрывает весь G4:
  нужны дополнительные проверки ошибок, гонок и переходов UI.
- Отдельно подтвердить создание профиля и кошелька в сервисах-владельцах;
  успешная регистрация сама по себе не является прямой проверкой их данных.

Spec 008 остаётся незавершённой; G5 выполнена частично.
