## Реализация

- [x] Добавить чтение назначенных ролей Identity через JPA-репозиторий.
- [x] Добавить claim назначенных ролей в выдачу access при регистрации, входе и refresh; основные пути проверены HTTP-тестами.
- [x] Проверить JWT и роли на изолированном тестовом потребителе без production endpoint.
- [x] Обновить документацию и примеры без настоящих токенов.

При тестировании на временной PostgreSQL проверены регистрация и вход с `USER`,
refresh после назначения `ADMIN`, а также отсутствие расширения ролей при
подписи. Тестовый потребитель проверяет роли и все уровни иерархии; его код
не используется production-сервисами. Проверены оба порядка удаления роли и
refresh при блокировке строки пользователя. Все критерии спецификации проверены. Полный Maven verify прошёл до последнего
дополнения теста; дополненный тест сбоя базы при входе и refresh и статический
анализ повторно прошли в verify Identity. Сквозной сценарий трёх сервисов
использовал временную PostgreSQL и временные сертификаты; проверены роли при
регистрации, входе и refresh. Необязательные smoke-тесты с локальным step-ca
пропущены без `fitness.localStepCaSmoke`. Публикация PR пока не выполнялась.
