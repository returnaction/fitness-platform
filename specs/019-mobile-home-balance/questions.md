# Вопросы и решения: мобильный Home с балансом

> **Спецификация:** [spec.md](spec.md)
> **Статус:** resolved

## Q001 — Где и какие значения показывать на первом Home-экране?

- **Затронутые задачи:** T001–T004.
- **Доказательства:** старый Flutter-клиент в
  `C:\Projects\python\flutter\app\mobile\lib\features\home\home_screen.dart`
  показывает в правой части `AppBar` доступные монеты с
  `Icons.monetization_on_outlined` и зарезервированные с `Icons.lock_outline`,
  разделяя их `VerticalDivider`. Действующий контракт Java возвращает те же
  две семантически разные величины camelCase.
- **Решение:** пользователь попросил сделать как в старом приложении. В новом
  Home баланс размещается в правой части AppBar в том же порядке: доступный,
  затем зарезервированный. Значения не суммируются.
- **Исключение:** прежняя кнопка daily reward не переносится: её endpoint и
  операция отсутствуют в согласованной Java-модели и Spec 019.
- **Статус:** принято 2026-11-16.

## Q002 — Можно ли повторить UI старого приложения?

- **Затронутые задачи:** T001, T004.
- **Доказательства:** пользователь указал отдельный checkout
  `C:\Projects\python\flutter\app\mobile`; в нём найден HomeScreen с
  индикаторами баланса в AppBar.
- **Решение:** переносится только расположение и компактное отображение
  баланса. Старый HTTP-клиент, snake_case поля, daily reward, challenges и
  серверные правила не переносятся автоматически.
- **Статус:** принято 2026-11-16.
