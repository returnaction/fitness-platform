Точные теги Java уже есть у шести сервисов; у Identity, Accounts и Coins
они плавающие. USER 10001 указан только у Gateway; у остальных восьми — нет.
Gateway входит в область проверки, но соответствующие требованиям настройки
менять не нужно. Модуль contracts/grpc-contracts — библиотека, не микросервис;
отдельного Dockerfile у него нет.

Отсутствие USER оставляет пользователя базового образа; фактический UID
образов нужно подтвердить при реализации. На момент исходной сверки загрузка и запуск образов не выполнялись;
результаты последующей проверки T003 записаны в tasks.md. Исходное замечание относится к запуску от root.

## Согласованный объём

1. Все девять сервисов из таблицы: запуск Java в финальном образе от UID 10001,
   как в Gateway. Это Linux-пользователь процесса, не роль пользователя приложения.
   Проверить доступ к jar, рабочему каталогу, временным файлам и необходимым
   конфигурациям/сертификатам. Не решать проблемы доступа выдачей прав всем.
2. Для сборочного и финального этапов всех девяти сервисов закрепить Temurin
   25.0.5+8: теги 25.0.5_8-jdk и 25.0.5_8-jre по примеру Gateway.
   Доступность тегов и фактическую версию подтвердить при реализации.
   Уже соответствующие настройки сохранить; обновлять только расходящиеся
   настройки и связанные пояснения, если они присутствуют.

Точный тег фиксирует выпуск Java, но не гарантирует неизменность всех байтов
образа. Закрепление digest сейчас не является согласованным требованием.
Сборочный этап не обязан работать от UID 10001: ограничение относится к
процессу приложения в финальном контейнере.

## Вне объёма

Серверное развёртывание, контейнерные сети, HTTPS, изменения gRPC-защиты,
бизнес-кода, API, БД, мобильного приложения. Не менять Maven
Wrapper или включать форматтер. Не трогать checkout ветки 41 и Spec 015.
Gateway включён в проверки наравне с остальными; новые прикладные функции не добавляются.

## Сценарии и критерии готовности

- [x] Все девять образов собираются из корня репозитория существующим способом.
- [x] В build-этапе java/javac показывают 25.0.5+8, в финальном — Java 25.0.5+8.

      прикладных контрактов. Результаты проверок записаны.
