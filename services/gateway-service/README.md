# Gateway Service

Реализация [Spec 012](../../specs/012-gateway-refactor/spec.md).
Создан каркас: настройки валидируются при запуске, API закрыт до реализации
маршрутов и проверки доступа. Проксирование ещё не подключено.
Добавлены собственный request ID, контекст общего deadline и единый JSON ошибок.
Сетевые вызовы по deadline пока не отменяются — это следующий этап транспорта.
Сервис не владеет БД и не запускает Liquibase.

## Настройки

Local — профиль по умолчанию. Скопируйте .env.example в .env внутри модуля
и задайте адреса Identity, issuer/audience и пути к TLS-файлам вашего окружения.
Local импортирует .env из текущего каталога и services/gateway-service/.env;
второй файл имеет приоритет. Секреты и .env не добавляются в Git.
Адреса в примере — образец, а не обнаруженные настройки Identity.

Production получает переменные окружения процесса, не импортирует .env
и требует HTTPS для Identity HTTP и JWKS. Логи — ECS.
Test импортирует test-environment.properties и не использует локальный .env.
Тестовые пути сертификатов фиктивные: gRPC-клиент ещё не создаётся.

Общий timeout в конфигурации — 3s. Management привязан к 127.0.0.1.
Загрузка ключей, readiness gate и доступ к management будут подключены
на следующих этапах; текущая защитная цепочка закрывает все HTTP-запросы.
