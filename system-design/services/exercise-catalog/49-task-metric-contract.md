# Снимок задания и метрика: проект v1

Единый проект формата задания, передаваемого Challenge → Moderation. Владение
условиями и сохранённым снимком — Challenge; каталог владеет определениями
упражнений. Снимок создаётся сервером из доверенных данных при публикации,
фиксируется для challenge и не изменяется из-за последующих правок каталога.
Телефон при загрузке видео не присылает модератору новое задание.

## Формат

```json
{
 "schema_version":1,
 "exercise_id":"<uuid>","variation_id":"<uuid>",
 "exercise_name":"Push-up","variation_name":"Narrow grip",
 "description":"Выполнить отжимания узким хватом",
 "instructions":"Поставьте руки ближе ширины плеч и выполните отжимания.",
 "target":{"metric":"REPETITIONS","value":10,"unit":"REP"}
}
```

`schema_version`, ID, названия, описание, инструкция `instructions` и `target`
обязательны; текстовые поля не пустые. `value` для v1 — целое положительное число, не JSON float;
единица однозначна и зависит от метрики. Снимок содержит только данные,
нужные для оценки задания, без имени участника, ставки и названия challenge.
Системные команды перед/после упражнения — отдельное доказательство Video
Proof и не трактуются как выполнение задания модератором.

| `metric` | `unit` | Пример | Значение |
| --- | --- | --- | --- |
| `REPETITIONS` | `REP` | `10` | 10 повторений. |
| `DURATION` | `SECOND` | `60` | Выполнять 60 секунд. |

Согласованный [стартовый список](57-exercise-catalog-service.md#согласованный-стартовый-каталог)
использует `DURATION` для планки и `REPETITIONS` для остальных упражнений.
Модератор видит единицу вместе с целью: например, «60 секунд» или «10 повторений».
Это проект данных, не утверждение, что в новом приложении упражнения уже настроены.
Верхние пределы значений,
длина текстов, локализация, допустимые единицы и свойства упражнений
определяются каталогом и проверяются при публикации. Неизвестный metric или
несовместимую пару metric/unit получатель не превращает в повторения: событие
ставится на технический разбор совместимости.

Вес, расстояние, калории и произвольные метрики пока **не объявлены готовыми**:
для них необходимо согласовать единицы, точность, способ проверки и ограничения.
Новое значение требует расширения версионированной схемы и поддержки всеми
получателями; одни новые значения enum без совместимости могут сломать очередь.
Несколько подходов — отдельные задания и отдельные записи, не массив подходов
в одном видео. Все задания дня обязательны по согласованным правилам.

Числовые ограничения и хранение `task_snapshot` определяются в единой
[модели Challenge](../challenge/38-challenge-data-model.md) и
[модели Moderation](../moderation/45-moderation-data-model.md), не отдельными таблицами здесь.
Перед реализацией сверить формат с Exercise Catalog и контрактом событий,
проверить старые снимки после деактивации упражнения и повторную доставку.
